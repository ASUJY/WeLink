# 登录模块功能
**已实现功能**
- [x] 支持使用昵称登录。客户端把非手机号格式的账号按昵称类型提交，昵称输入不限制英文或中文。
- [x] 支持使用中国大陆手机号登录。
- [x] 支持输入密码，密码框以隐藏字符显示。
- [x] 输入框提供“手机号/用户名”“请输入密码”提示。账号或密码为空时不提交登录请求。
- [x] 登录页提供“注册帐号”入口，可打开注册窗口。
- [ ] 可显示登录失败、用户未注册、用户已在线等服务端返回提示；登录成功后进入主窗口，并处理登录响应携带的离线消息。


**未实现功能：**
- [ ] 密码长度和复杂度校验。
- [ ] 登录失败、网络不可用、服务端异常时给出明确提示。
- [ ] 自动登录，增加记住密码或自动登录前，先设计安全的本地凭据保存方式。
- [ ] 记住密码
- [ ] 支持退出登录，并清理当前账号的界面状态。
