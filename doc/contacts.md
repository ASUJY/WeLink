# 联系人与好友申请 模块
**已实现功能**
- [x] “添加朋友”入口可通过昵称或手机号搜索用户；手机号按与登录相同的规则识别。
- [x] 搜索结果可展示用户信息，并可发起好友申请；对方可在“新的朋友”中接受或拒绝申请。
  - [x] 如果搜索结果已经是自己的好友，则直接展示用户信息，不能发起好友申请
- [x] 收到申请后显示申请人；
  - [x] 接受后加入联系人列表和聊天会话列表，并更新申请状态。
  - [x] 拒绝操作会发送拒绝状态。
- [x] 联系人及好友申请在客户端侧写入 SQLite；登录后会读取本地联系人及申请记录。
- [x] 可从联系人列表选择条目并查看对应的申请/联系人状态页面。


**未实现功能**
- [] 联系人页、聊天页中的搜索框目前没有实际过滤逻辑。
