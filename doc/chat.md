#  聊天模块
**已实现功能**
- [x] 展示聊天会话列表；选择会话后在聊天框显示联系人名称和已有消息。
- [x] 在聊天框可输入并发送非空文本消息；空内容不会发送。
- [x] 收到单聊消息后，在对应会话(聊天列表项)中显示消息气泡，更新会话预览、时间和未读计数。
- [x] 点击会话会清除其未读提示，并打开对应聊天框。
- [x] 登录响应中携带的离线单聊消息会交给聊天界面处理。
- [x] 消息在本地 SQLite 中保存；登录初始化时会读取已有好友对应的消息记录。


**未实现功能**
- [ ] 聊天窗口工具栏中的表情、文件等图标目前没有对应的发送处理；
- [ ] 会话列表搜索框和“选项2”菜单项也尚未接通功能。
- [ ] 通讯录和聊天会话数据的本地读写已存在，但服务端同步、异常恢复、重复申请处理等完整性仍需结合服务端协议和实际运行进一步验证。
